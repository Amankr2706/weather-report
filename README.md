# 🌦️ Weather Report

A simple weather web app built with **HTML, CSS, and JavaScript** that fetches real-time weather data using the **OpenWeatherMap API**.  
It shows the current temperature, weather condition, humidity, wind speed, and more for any city entered by the user.

---

## 🚀 Features
- Search weather by **city name**
- Displays:
  - 🌡️ Current temperature
  - 🌦️ Weather description (clear, cloudy, rainy, etc.)
  - 💧 Humidity
  - 🌬️ Wind speed
  - 🌡️ Min / Max temperature
- Responsive UI with clean design

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **OpenWeatherMap API**
